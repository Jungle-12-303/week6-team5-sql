# 세션 로그

## 요청 요약

- `refactoring` 브랜치의 코드 베이스를 바탕으로 초심자도 이해할 수 있는
  시각화가 포함된 Markdown 자료를 추가한다.

## 결정 사항

- 별도 문서 `docs/refactoring-visual-guide.md`를 추가한다.
- mermaid를 사용해 전체 구조, 입력 모드, INSERT 흐름, SELECT 흐름,
  B+ 트리 구조를 시각화한다.

## 현재 브랜치 상태

- 현재 브랜치는 `refactoring`이다.

## 완료한 작업

- `refactoring` 브랜치 기준 구조를 읽기 쉽게 설명한 문서를 추가했다.
- REPL/파일 모드, INSERT/SELECT 실행, B+ 트리 구조를 mermaid로 시각화했다.
- 초심자가 코드를 읽는 추천 순서와 자주 헷갈리는 포인트도 함께 정리했다.
