# 세션 로그

## 요청 요약

- SQL 파서를 구현하고 `INSERT`, `SELECT`, `CREATE INDEX`를 읽을 수 있게
  만든다.

## 결정 사항

- 토크나이저와 수동 파서를 분리한다.
- AST는 고정 크기 배열 기반으로 두어 초심자가 추적하기 쉽게 유지한다.
- `WHERE`는 최대 2개의 `AND` 조건만 허용한다.

## 현재 브랜치 상태

- 최신 `dev`에서 `feature/sql-parser` 브랜치를 만들었다.

## 완료한 작업

- 공용 타입과 토큰 타입을 헤더에 추가했다.
- 토크나이저와 파서를 구현했다.
- 파서 단위 테스트를 추가했다.
- AST에 위치 정보를 남기도록 보강했다.
- `run_program` 실제 파일 읽기 경로를 테스트에 포함했다.

## 리뷰 결과

- 기본 `make` 타깃 문제와 빈 SQL 파일 성공 처리 문제를 수정했다.
- 초심자 가독성을 해치던 삼항식과 불필요한 반환값을 정리했다.

## 다음 작업

- 파서 브랜치 테스트를 통과시키고 GitHub 워크플로를 진행한다.

## 남은 리스크

- 실행기는 아직 실제 파일 저장과 조회를 수행하지 않는다.
