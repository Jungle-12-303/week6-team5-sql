# 세션 로그

## 요청 요약

- 다른 Codex 에이전트도 바로 작업을 이어받을 수 있도록 공용 컨텍스트와
  작업 규칙을 담은 에이전트 지침 Markdown 파일을 만든다.

## 결정 사항

- 루트 `AGENTS.md` 하나에 프로젝트 상태, 구현 범위, 코드 스타일,
  GitHub 워크플로, 커밋 규칙, 세션 로그 규칙을 함께 담는다.
- 최신 `dev` 기준 구현 상태를 반영하기 위해 REPL 모드와 PRIMARY KEY 지원도
  포함한다.

## 현재 브랜치 상태

- 최신 `dev`에서 `feature/agent-guidelines` 브랜치를 만들었다.

## 완료한 작업

- 루트 `AGENTS.md`를 추가했다.
- 현재 구현 기능, 파일별 책임, 테스트 방식, 브랜치 전략, GitHub Project 절차,
  멀티 페르소나 리뷰 역할, 커밋 메시지 규칙을 문서화했다.
- 최신 `dev`에 반영된 REPL 입력 모드와 PRIMARY KEY 스키마 규칙도
  함께 정리했다.

## 리뷰 결과

- 정확성/문서-구현 일치 관점에서 최신 README, `include/sqlproc.h`,
  `src/app.c`, 최신 세션 로그를 대조했고 현재 기준 차단 이슈는 없다.
- 워크플로/운영 규칙 관점에서 브랜치 전략, GitHub Issue/Project/PR 절차,
  세션 로그 규칙을 다시 확인했고 현재 기준 차단 이슈는 없다.
- 초심자 가독성 관점에서 저장소 전반의 문서와 주석 구성이 무리 없는 수준이라는
  검토 결과를 확인했고 `AGENTS.md`도 같은 방향으로 정리되어 있다.
- 현재 `make test`가 통과한다.
