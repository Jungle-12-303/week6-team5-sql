# 세션 로그

## 요청 요약

- 실제 파일 기반 INSERT와 SELECT WHERE 실행기를 구현한다.

## 결정 사항

- 데이터 저장 포맷은 CSV를 유지한다.
- WHERE 평가는 우선 full scan으로 처리하고, CREATE INDEX 실행은 다음
  B+ 트리 브랜치에서 완성한다.
- 실행기 테스트는 임시 디렉터리와 실제 파일 입출력 기반으로 추가한다.

## 현재 브랜치 상태

- 최신 `dev`에서 `feature/where-executor` 브랜치를 만들었다.

## 완료한 작업

- 스키마 로더와 CSV 저장/조회 코드를 추가했다.
- INSERT와 SELECT WHERE 실행 경로를 연결했다.
- 파일 기반 통합 테스트를 추가했다.

## 리뷰 결과

- 아직 merge 전 멀티 페르소나 리뷰는 진행 전이다.

## 다음 작업
